# 병원 검색 순위 대시보드

여러 병원의 네이버 플레이스·블로그 순위와 경쟁 병원 현황을 분석하고 날짜별 결과를 Supabase에 기록하는 Next.js 앱입니다.

## 실행 준비

1. Supabase 프로젝트를 만들고 SQL Editor에서 [`supabase/schema.sql`](./supabase/schema.sql)을 실행합니다.
2. 프로젝트의 API 설정에서 Project URL과 `service_role` 키를 확인합니다.
3. 이 폴더에 `.env.local` 파일을 만들고 서버 환경변수를 설정합니다.

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

`SUPABASE_SERVICE_ROLE_KEY`는 데이터베이스 관리자 권한이 있는 비밀 키입니다. 브라우저 코드, 공개 저장소 또는 `NEXT_PUBLIC_` 환경변수에 넣지 말고 로컬 `.env.local`과 배포 플랫폼의 서버 환경변수에만 저장하세요.

```powershell
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 플레이스 분석에는 Puppeteer가 사용하는 Chromium이 필요합니다. 설치된 Chrome을 지정하려면 서버 환경변수 `CHROME_PATH`에 실행 파일 경로를 설정하세요.

## 병원 등록과 분석

- **새 병원 등록**에서 병원명, 네이버 플레이스 URL 또는 ID, 블로그 주소, 키워드를 저장합니다.
- 병원을 선택한 뒤 **추적할 경쟁 병원** 영역에서 경쟁 병원명, 플레이스 URL 또는 ID, 블로그 주소를 등록합니다. 경쟁 병원별로 등록한 플레이스와 블로그의 순위를 기준 병원의 키워드마다 비교합니다.
- 경쟁 병원 등록·수정·삭제 후 해당 병원의 오늘 분석을 다시 실행해 비교 결과를 갱신합니다. 과거 날짜의 저장된 분석은 당시 결과 그대로 유지됩니다.
- 병원을 선택하거나 저장하면 해당 병원의 오늘 기록이 없을 때 자동으로 분석하고 저장합니다. 같은 날 다시 접속하면 이미 저장된 결과를 보여줍니다.
- **저장하고 분석하기**는 같은 날에도 새로 분석하여 오늘 기록을 갱신합니다.
- 여러 키워드는 쉼표 또는 줄바꿈으로 구분하며 병원당 최대 20개까지 입력할 수 있습니다.
- 날짜별 표에서 날짜를 선택하면 해당 날짜의 플레이스·통합검색·블로그 분석을 다시 볼 수 있습니다. 최근 7일 또는 30일 기록을 표시합니다.
- **PDF로 저장**은 브라우저의 인쇄 창을 열며, 대상에서 “PDF로 저장”을 선택하면 현재 분석과 날짜별 표를 PDF로 저장할 수 있습니다.

하루 한 번 수집은 해당 병원을 대시보드에서 조회할 때 수행됩니다. 앱에 접속하지 않은 날에는 새 기록이 생성되지 않으며, 과거 날짜의 기록을 소급해서 만들 수 없습니다.

## 공개 접속 관련

현재 버전은 로그인을 요구하지 않습니다. 대시보드 URL에 접속 가능한 사람은 공용 병원 목록과 검색 설정을 보고, 변경·삭제할 수 있으며 분석을 실행할 수 있습니다. 공개 인터넷에 배포할 경우 URL만 공유해도 된다는 운영 방침을 확인하세요. 병원 목록을 보호해야 한다면 공개 배포 전에 인증 기능을 추가해야 합니다.

브라우저는 Supabase에 직접 접속하지 않습니다. 서버 API만 `service_role` 키를 사용하며, 이 키는 서버에만 보관해야 합니다.

## 순위 해석

- **플레이스 순위**는 네이버 지도 검색 결과에서 플레이스 ID를 찾아 계산합니다.
- **통합검색 순위**는 검색 페이지에서 확인 가능한 네이버 플레이스 결과 안에서의 노출 순서입니다. 통합검색 전체의 고정 순위가 아니며, 검색환경·개인화·네이버 페이지 구조에 따라 달라질 수 있습니다.
- **블로그 순위**는 네이버 블로그 검색 결과에서 입력한 블로그 주소와 일치하는 글의 순서입니다.
- **경쟁 병원**은 첫 번째 키워드의 네이버 지도 검색 결과를 기준으로 표시합니다.
- **등록한 경쟁 병원 비교**는 플레이스 ID와 블로그 주소를 기준으로 키워드별 순위를 확인합니다. 플레이스 검색 수집 범위(상위 30개)를 벗어난 병원은 “순위권 외”로 표시됩니다. 기준 병원을 포함해 한 번에 최대 30개 플레이스까지 비교합니다.

네이버 검색 결과의 구조, 노출 정책 또는 접속 제한이 바뀌면 일부 결과를 수집하지 못할 수 있습니다.
